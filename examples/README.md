# Example reports

This folder holds real audit runs, so people can see the output before installing.

To add one:
1. Run `/site-audit:audit <url>` on a public page. Your own site is best, or one whose owner is fine with a public critique.
2. Copy the resulting `site-audit-reports/<site>-<date>/` folder here.
3. Link its `REPORT.md` from the main README.
